# 留在場外｜戒賭運彩模擬帳戶 V1.0

一款獨立的靜態網頁作品。**不接受現金、沒有付款或提款功能，不代表台灣運動彩券官方。**

## 已實作
- 第一次使用時建立初始虛擬資金（預設 10,000 點），無追加點數功能。
- 籃球、棒球、足球、網球、排球的 **虛構示範賽事**，單場／串關模擬投注。
- 投注時鎖定賠率、扣除虛擬點數、保存時間與選項。
- 手動登錄賽果、結算中獎／未中／作廢退款，更新餘額與流水。
- 每日投入額上限、24 小時暫停投注、已結算損益與未結算風險。
- 使用瀏覽器 `localStorage` 保存紀錄，支援完整 JSON 備份匯出、還原。
- 手動新增真實或自行設計的賽事；JSON 賽事匯入／可選擇 HTTPS 公開 JSON 來源同步。

## 如何開啟
解壓 ZIP，使用瀏覽器開啟 `sports-sim/index.html`，或將它上傳至 GitHub Pages 儲存庫根目錄。無需 npm、資料庫、帳戶或 API key。

## 保留與同步限制
- **保留：** 同一瀏覽器、同一網站網域／儲存空間內，重新開啟網頁仍在。
- **無法保證：** 跨手機、多裝置同步，或使用者清除網站資料後保留。請定期「資料管理 → 匯出完整備份」。
- 將 `file://` 本機 HTML 換成 GitHub Pages 後，網站儲存區不同，請先匯出後匯入。
- 如需跨裝置自動同步，下一版需登入系統及雲端資料庫（Supabase/Firebase 類型），並建立資料存取規則。

## 即時台灣運彩資料
截至目前查證，未找到可確認可供普通網站直接使用的**免授權台灣運彩官方公開賠率 API**。第三方 JBot 提供台灣運彩資料 API，但需要自行向供應者取得金鑰、遵守授權和額度。

**本版不能自動抓取台灣運彩當日賠率，也不會自動取得真實賽果。** 用戶可自行輸入，或從經合法取得、且允許 CORS 的 JSON 資料源匯入。前端絕不可直接填寫私人 API key；有授權 API 時應透過你自己的後端代理安全串接。

匯入格式（`games` 陣列）：
```json
{"games":[{"id":"match-001","sport":"籃球","league":"自有資料來源","away":"客隊","home":"主隊","startsAt":"2026-11-01T12:00:00+08:00","odds":{"away":1.90,"home":1.85}}]}
```

- `id` 必須穩定且唯一；更新同 id 外部賽事時，可更新未結算賽事的賠率；已下單的票券不變。
- 足球三選一可加入 `"draw":3.10`。
- 手動賽果登錄不可撤回（為確保流水一致）。
- 串關按各腿小數賠率相乘，並以手動結果結算；**不表示完全符合台灣運彩正式串關限制及特殊玩法規則**。

## 授權與安全提醒
本專案不隸屬或代表台灣運彩。勿利用未經許可的抓取方式繞過官方網站保護或將第三方 API 金鑰直接放到公開 GitHub Pages。
